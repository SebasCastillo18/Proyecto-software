# Proyecto-software

A concise and professional academic web project focused on improving access to key student information.

Proyecto-software is a frontend project developed with React, Vite, JavaScript, CSS, and collaborative version control through Git and GitHub.  
It was created to promote reading and understanding of the student regulations and tuition-free education policies. The application allows random article display from the student regulations, specific article search by number or text, and FAQ browsing for the gratuity policy with text-based search.  
This project helped reinforce practical skills in frontend development, reusable component design, collaborative work, and structured data handling with JSON.

## Tech Stack
- React
- Vite
- JavaScript
- CSS
- Git and GitHub

## Features
- Random article display from the student regulations
- Search by article number or text
- FAQ section for gratuity policy with text-based search
- External links to the corresponding official institutions

## Purpose
Developed as part of an academic process to strengthen skills in frontend development, teamwork, and the creation of useful technological solutions for the student community.

## Status
Completed and preserved as part of portfolio.

Due to the project scope, databases and APIs were not used, so the information was structured in JSON files as a functional and viable academic solution.
